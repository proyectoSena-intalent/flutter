REDISEÑO VISUAL INTALENT
=======================

Cambios incluidos:
- 15 templates HTML enlazados a la nueva hoja visual.
- static/css/intalent-ui.css: estilos responsivos y componentes visuales.
- static/img/hero-inicio.webp: recurso visual para el banner principal.

Integridad:
- No se modificaron archivos Python (.py), URLs, modelos, vistas ni configuración.
- Se conservaron las etiquetas y expresiones de Django existentes.
- Se conservaron los atributos y métodos de los formularios, los tokens CSRF y los scripts funcionales.
- No se añadieron dependencias externas ni CDN.

Prueba local:
1. Descomprime el proyecto y abre la carpeta intalent_backend en VS Code.
2. Activa tu entorno virtual.
3. Ejecuta: python manage.py runserver
4. Abre: http://127.0.0.1:8000/inicio/

Nota:
La comprobación `python manage.py check` no se pudo ejecutar en este entorno de preparación porque aquí no está instalado Django. Ejecútala en tu entorno virtual local.
En despliegues de producción, ejecuta `python manage.py collectstatic` según la configuración del servidor.

CORRECCION DE ARCHIVOS ESTATICOS (25/11/2026)
Los recursos CSS e imagen se ubican en:
  usuarios/static/css/intalent-ui.css
  usuarios/static/img/hero-inicio.webp

Se colocan dentro de usuarios/static porque 'usuarios' está en INSTALLED_APPS.
Django puede encontrarlos con AppDirectoriesFinder sin modificar settings.py.
No se modificó ningún archivo Python.
Para comprobarlo en el entorno virtual:
  python manage.py findstatic css/intalent-ui.css --verbosity 2
Debe mostrar la ruta usuarios/static/css/intalent-ui.css.
